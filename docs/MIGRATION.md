# 重建版迁移状态

当前仓库基于 OpenSumi 上游 `9a7057aec`，移植了原本地项目的框架、IDE 入口和工作台界面，将工作台控制面实现为 Node.js/Koa 服务。本文件记录本次提交包含的能力与验证边界。

## 已完成的范围

| 范围         | 当前实现                                                                                  |
| ------------ | ----------------------------------------------------------------------------------------- |
| 工具链       | Node 24.16.0、pnpm 12.8.1、TypeScript 7.0.2、Rspack 2.2.8；保留 TS 6 编译器 API 兼容别名  |
| 框架         | 工作区依赖与公开包入口整理，类型检查与资源复制，保留 OpenSumi/VS Code 扩展兼容接口        |
| 产品入口     | 独立 `client/`、`server/` 与工作台 `application/`；根启动校验并补齐产物                   |
| 项目与工作区 | Git 导入、仓库浏览、提交与分支基线、固定基线工作树、工作区启动/停止/重置/删除             |
| 持久化       | Node 原生 SQLite 元数据、凭据加密、账户会话、个人开发机与工作区唯一约束                   |
| 运行控制     | 分资源生命周期队列、本机 Node IDE 子进程、一次性入场凭据、HTTP/WebSocket 工作区代理       |
| 沙箱         | 官方 OpenSandbox JavaScript SDK、机器分配与恢复、端点认证头代理、受管生命周期和管理员接口 |
| Maven        | 项目 Wrapper 子进程、机器级互斥、取消、日志脱敏、历史与配置辅助工具                       |
| 插件         | 72 个配置内置插件的下载、断点续传、完整性与入口检查、预计算扫描索引                       |
| 共享 watcher | 显式实验开关、服务级单例池、连接租约、策略隔离、事件关联字段移除与回收                    |

界面沿用原工作台的项目、工作区、代码源、开发机、镜像、沙箱等页面。页面存在不代表对应的每个旧 Go 后端接口已迁移，未实现项见下节。

## 尚未完成与未验收

- 开发资源配置、协议探测、对象存储与编辑器连接的完整控制面接口。
- IDE Git 凭据桥、用户提交发布及 GitLab/GitHub/Gitee 的 MR/PR 流程。
- 开发服务自动启动、独立预览域名、运行日志与停止过程的完整联动。
- 开发机备份/恢复、空闲回收策略、自动备份、资源指标与缓存清理。
- 实际运行时升级、孤儿 IDE 恢复、跨账户操作系统隔离和真实 PVC 删除后端。
- Node 24 Docker 构建入口、旧工作流迁移、实际 OpenSandbox 镜像与端到端远程验收。
- 原本地实现与最新上游存在差异，上游新增功能的完整回归仍需补齐。
- Windows/Linux 本版产品运行验收、共享 watcher 崩溃自动重订阅与活跃浏览器连接下的 Server 退出验收。

运行产品固定为 Node 模式；框架内仍有历史 Go 协议适配器、诊断脚本和兼容测试。Maven 元数据解析仍有 Python 辅助程序，Docker 运行配方仍需完善。不能将本次提交描述为全部旧功能已纯 Node 化或生产部署已完成。

上述结果不是整个平台的完整浏览器回归、长期稳定性或生产容量证明。Maven 测试使用可控的项目 Wrapper，沙箱测试使用官方 SDK 协议夹具，未替代真实远程运行或真实 Maven 依赖下载。

构建保留 13 个警告：IDE 客户端 7 个 CSS 顺序警告，组件分发包 2 个包大小警告和 1 个 `__filename` 模拟警告，Monaco Worker 3 个包大小与性能建议警告。这些构建成功结果未包含上述事项的修复或性能验收。

2026-10-02 拆分提交后重新执行整套构建、39 个 watcher 测试、8 个工作台测试、4 个插件测试、工程脚本类型检查和 72 个插件校验，均通过。Git 钩子的格式化与 ESLint 写入任务改为串行执行，根 `package.json` 中重复的工作台测试命令已移除。

共享 watcher 的历史性能结果保存在 [原实验记录](architecture/shared-node-watcher-experiment-20261001.md)；本版仅验证进程共享、文件事件隔离与清理，不据此宣称完整 IDE 的内存或延迟改善。本机原始性能记录保留于忽略的 `output/runtime-profiles/`。
